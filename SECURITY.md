# Security and privacy

This repository demonstrates a local AI/automation prototype. It must not contain credentials, private network layouts, or user activity data.

- Publish sanitized configuration **examples**, not live Home Assistant directories.
- Keep Wi-Fi passwords, API encryption keys, OTA passwords, tokens, and IP/device identifiers private.
- Review dashboard photos for location, accounts, personal calendars, people, and endpoint URLs.
- Revoke and rotate any credential accidentally committed; removing it from a subsequent commit does not erase its history.
- Only use publicly releasable test data and non-sensitive demonstration equipment.
